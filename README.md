# 📊 Sales Performance and Business Analytics Dashboard | Power BI

## 📌 Project Overview

This project is an interactive **Sales Performance and Business Analytics Dashboard** developed using Microsoft Power BI. It provides insights into sales performance, revenue targets, customer behavior, product performance, order status, and returns.

The dashboard contains multiple report pages with interactive visualizations, KPI cards, charts, and filters to help users analyze business performance and make data-driven decisions.

## 🎯 Project Objectives

- Analyze overall sales performance and profitability.
- Compare net sales against revenue targets.
- Understand customer purchasing patterns and sales trends.
- Identify top-performing products and product categories.
- Evaluate sales team performance.
- Monitor order fulfillment, cancellations, and returns.
- Present business insights through interactive dashboards.

## 🛠️ Tools and Technologies

- **Microsoft Power BI Desktop** – Dashboard development and data visualization
- **Power Query** – Data cleaning and transformation
- **DAX (Data Analysis Expressions)** – KPI calculations and measures
- **Data Modeling** – Organizing data for analysis
- **Excel / CSV** – Data sources, where applicable

## 📑 Dashboard Pages

### 1. Executive Overview
Provides a high-level view of business performance through key metrics and summary visualizations.

### 2. Sales Performance & Targets
Analyzes net sales, revenue targets, target attainment, and variance to target. Includes employee-level comparisons and monthly performance trends.

### 3. Customer Insights
Provides a dedicated page for exploring customer-related information and purchasing patterns.

### 4. Product & Category Analysis
Evaluates product performance and category-level sales contribution using scatter plots, rankings, bar charts, treemaps, and pie charts.

### 5. Sales Team Performance
Compares net sales and gross profit across employees and analyzes revenue target performance over time.

### 6. Returns & Operations
Tracks returned units, return rate, return reasons, order status, and delivery performance.

### 7. Order Details
Provides detailed order analysis using sales channel, region, product category, customer, order status, and quantity-based visualizations.

## 📊 Visualizations and Features

- KPI cards for key business metrics
- Bar and column charts for sales comparisons
- Line and area charts for time-based trends
- Treemaps for employee and category contribution
- Scatter plots for product metric analysis
- Donut and pie charts for return reasons and profit contribution
- Tables and matrices for detailed comparisons
- Interactive slicers for region, category, sales channel, and other dimensions
- Cross-filtering and drill-down analysis where configured

## 🔍 Business Insights

The dashboard helps users investigate questions such as:

- How are actual net sales performing against revenue targets?
- Which employees contribute the most to sales and gross profit?
- Which products and categories perform best?
- What are the main reasons for product returns?
- How many orders are completed, returned, or cancelled?
- How does performance vary by region, month, and sales channel?

## 🚀 How to Use

1. Download the `.pbix` report from this repository.
2. Install Microsoft Power BI Desktop.
3. Open the `.pbix` file.
4. If prompted, update the data source paths to match your local files.
5. Refresh the data if the source files are available.
6. Explore the report pages and interact with the filters and visualizations.
